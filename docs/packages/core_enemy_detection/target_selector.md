# target_selector

## Purpose

`target_detector` は視野内のダメージパネル候補をすべて出力しますが、砲身は一度に1つのターゲットしか狙えません。このノードは候補群から狙うべき1つを決定し、照準ノードが直接使える形式に変換します。

## Inner-workings / Algorithms

`damage_panels_infomation` を受信すると、候補の中から**面積が最大のもの**を選択します。画像上の面積は距離のおおまかな逆指標になるため、最も近い（＝当てやすく、脅威度が高い）敵を狙う挙動になります。

選択したパネルの重心を、画像中心を原点とする座標系に変換して `damage_panel_pose` として発行します。`image_size` パラメータが座標変換の基準となります。

候補が1つもない場合は `z = 1.0` を設定したメッセージを発行します。下流の [aim_bot](../core_shooter/aim_bot.md) はこの値を「ターゲット未検出」のフラグとして解釈し、追尾を停止します。ターゲットの有無を別トピックに分けず、同一メッセージ内で表現する設計です。

## Inputs / Outputs

### Input

| トピック | 型 | 説明 |
|---------|------|------|
| `damage_panels_infomation` | `core_msgs/DamagePanelInfoArray` | 検出されたダメージパネル候補（`target_detector` から） |

### Output

| トピック | 型 | 説明 |
|---------|------|------|
| `damage_panel_pose` | `geometry_msgs/PointStamped` | ターゲット位置（画像中心が原点）。`z=1.0` で未検出を表す |

## Parameters

設定ファイル: `config/sim_param.yaml`

| パラメータ | 型 | デフォルト | 説明 |
|-----------|------|-----------|------|
| `image_size` | int[] | `[1280, 720]` | 入力画像サイズ [幅, 高さ]。座標変換の基準 |

## Assumptions / Known limits

- 選択基準は面積のみです。画面中央への近さ、移動方向、過去フレームでの選択履歴などは考慮しません。
- 面積を距離の代理指標としているため、パネルが部分的に隠れている敵は実際より遠いと評価されます。
- フレームごとに独立して選択するため、同程度の面積の候補が2つある場合、ターゲットがフレーム間で交互に切り替わって照準が振動する可能性があります。ヒステリシスは実装されていません。
- `image_size` は `target_detector` 側の設定と一致させる必要があります。不一致の場合、出力座標に系統的なオフセットが生じます。
